# Interface previews

These images come from the iPhone 16 Pro simulator UI tests. The home and setup screens contain no session data. Files named test-fixture use synthetic session numbers solely to verify layouts and navigation. They are not real movement measurements or validation evidence.

- home-light.png and home-dark.png: home in both appearances.
- setup-light.png and setup-spanish.png: preparation in English and Spanish.
- result-test-fixture.png: result layout with synthetic numbers.
- large-text-actions-test-fixture.png: result controls at the largest Dynamic Type size.

- routine-library.png: the five supported camera routines.
- custom-camera-setup-test-fixture.png: a custom template using a supported routine.
- manual-count-test-fixture.png: an explicitly manual count and PDF controls.
- local-plan-test-fixture.png: a locally entered plan, with reminders disabled.

These expansion previews were refreshed on October 25, 2026. The result fixture remains synthetic. Minor wording changes after the full-run screenshots are documented in feature-expansion.md.

- result-meaning-test-fixture.png: the new plain-language number explanation, using synthetic angles.
- hands-free-waiting-simulator.png: the armed waiting state with camera access disabled by the UI-test harness. Its black preview is deliberate. This is not hardware camera evidence.

- today-plan-test-fixture.png: a locally entered plan with skip and undo exercised; notifications are off.
- report-consent-large-test-fixture.png: PDF preview and sharing confirmation at the largest text size, using synthetic values.
